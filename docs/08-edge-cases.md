# 8. Edge-case handling matrix

Test files: `U-SM` = `tests/unit/test_state_machine.py`, `U-AL` = `tests/unit/test_allocation.py`,
`U-RU` = `tests/unit/test_rules.py`, `A-AU` = `tests/api/test_auth_and_access.py`,
`A-IS` = `tests/api/test_intake_and_storage.py`, `A-PU` = `tests/api/test_pickup.py`,
`A-RE` = `tests/api/test_reliability.py`.

| # | Edge case | Handling | Response | Proven by |
|---|---|---|---|---|
| 1 | Duplicate courier tracking ID | Tracking IDs normalised (spaces removed, upper-case); `UNIQUE(tracking_id)`. The rejected attempt is written to the audit log (committed) before refusing; response includes the existing package code/ID. A race between two registrations is caught by the constraint. | 409 `DUPLICATE_TRACKING_ID` | A-IS `test_duplicate_tracking_id_is_rejected_and_audited`, U-RU `test_tracking_ids_are_normalised…` |
| 2 | Missing or unidentified recipient | Registration allowed with `recipient_hint`; status `UNIDENTIFIED`; incident opened automatically; later `POST /recipient` moves it to VERIFIED/STORED and resolves the incident. | 201 | A-IS `test_unidentified_package_enters_workflow_and_can_be_identified` |
| 3 | Invalid learner ID | Must match an active learner; the error tells staff to register as unidentified instead. | 422 `LEARNER_NOT_FOUND` | A-IS `test_invalid_learner_id_is_rejected_with_guidance` |
| 4 | Learner views another learner's package | List is scoped server-side to `recipient_id = me`; direct access returns 404 so IDs cannot be probed. History and pickup requests are also scoped. | 404 | A-AU `test_learner_sees_only_their_own_packages`, A-PU `test_learner_cannot_request_pickup_for_someone_elses_package` |
| 5 | Unauthorised admin operation | `require(Permission.X)` on every route; permission table per role. | 401 / 403 | A-AU `test_learner_cannot_perform_staff_operations`, `test_security_cannot_perform_admin_operations`, U-RU `test_role_permission_boundaries` |
| 6 | Assignment to a full location | Atomic conditional increment; `CHECK occupied_count <= capacity`. Auto-allocation tries the next candidate. | 409 `STORAGE_FULL` | A-IS `test_full_location_rejects_additional_allocation`, `test_concurrent_allocation_never_exceeds_capacity` |
| 7 | Storage location becomes unavailable | Admin closes it (`is_active=false`): current packages stay, new allocations rejected, strategies skip it. Capacity cannot drop below occupancy. Too-small shelf also rejected. | 409 `STORAGE_UNAVAILABLE`, 422 `STORAGE_SIZE_MISMATCH` / `CAPACITY_BELOW_OCCUPANCY` | A-IS `test_unavailable_location_and_size_mismatch_are_rejected`, `test_capacity_cannot_drop_below_occupancy` |
| 8 | Invalid, expired or reused pickup token | Hash compared in constant time; expiry 30 min; `used_at`/`revoked_at` checked; wrong attempts counted and code locked after 5. | 400 `PICKUP_CODE_INVALID` / `_EXPIRED` / `_USED` / `_REVOKED` / `_LOCKED`; 409 `ALREADY_COLLECTED` | U-RU `test_unusable_tokens_are_rejected…`, A-PU `test_expired_code…`, `test_code_locks_after_too_many…`, `test_requesting_again_revokes…`, `test_reused_code_and_already_collected…` |
| 9 | Wrong learner attempts pickup | Learner ID entered by staff (from the ID card) must match the recipient, and the token must belong to the recipient. Counts as a failed attempt. | 400 `PICKUP_WRONG_RECIPIENT` | A-PU `test_wrong_code_and_wrong_learner_are_rejected_and_counted` |
| 10 | Package already collected | Terminal state; no transitions out; pickup request and handover both refuse. | 409 `ALREADY_COLLECTED` / `INVALID_STATUS_TRANSITION` | A-PU `test_reused_code_and_already_collected…`, U-SM `test_collected_package_can_never_become_ready_again` |
| 11 | Two staff collect simultaneously | Row lock + conditional token update + conditional status update + `UNIQUE(pickup_records.package_id)`. | one 201, one 409 | A-PU `test_concurrent_handover_results_in_exactly_one_collection` (PostgreSQL and SQLite) |
| 12 | Repeated requests from network retry | `Idempotency-Key` on registration and handover replays the original result; same key with a different body is rejected. Pickup-code requests are safe to retry (new code supersedes old). | 200 + `Idempotent-Replayed: true`; 409 `IDEMPOTENCY_KEY_REUSED` | A-IS `test_idempotent_registration_replays…`, A-PU `test_network_retry_of_handover_is_replayed` |
| 13 | Notification fails after successful update | Event published after commit; rows saved PENDING first; failing channel marked FAILED with error; never raises into the request; admin retry. The in-app record is never described as "delivered". | 200 for the update | A-RE `test_notification_failure_does_not_undo_the_package_update`, U-RU `test_event_bus_isolates_failing_subscribers` |
| 14 | Damaged on arrival | Condition `DAMAGED` requires notes; status `DAMAGED` hold; incident opened; staff can release to storage, investigate or return. Condition stays DAMAGED. | 201 | A-IS `test_damaged_package_is_held_and_incident_opened` |
| 15 | Uncollected beyond deadline | Derived overdue flag (configurable days); overdue filter, dashboard count, "Needs attention" queue, learner warning. Status unchanged. | – | A-RE `test_overdue_packages_are_flagged_and_filterable`, U-RU `test_overdue_is_derived…` |
| 16 | Return to courier | Admin `RETURN_REQUESTED` (reason required); staff `RETURNED`; shelf released; learner notified. | 200 | A-RE `test_return_to_courier_flow_releases_storage` |
| 17 | Security staff changes shifts | No package is "owned" by a guard; any active security user continues the workflow. Each action records the real actor (`received_by`, `handed_over_by`, history, audit). Incidents can record shift notes. Deactivated staff lose access at once. | – | A-PU `test_shift_change_does_not_block_the_workflow`, A-AU `test_deactivated_user_loses_access_immediately` |
| 18 | DB operation fails halfway | One transaction per use case; any exception rolls back everything; generic 500 without internals plus a request ID. | 500 `INTERNAL_ERROR` | A-RE `test_failure_halfway_through_handover_rolls_everything_back` |
| 19 | Invalid input, missing fields, malformed JSON | Pydantic validation with field-level messages; cross-field rules (damage notes, recipient or hint, no future arrival). | 422 `VALIDATION_FAILED` with `details[]` | A-IS `test_missing_and_malformed_fields_return_field_errors` |
| 20 | Unauthorised access to history or audit | Audit log is admin-only; package history follows package visibility; learners see history without staff names or reasons. | 403 / 404 | A-AU `test_security_cannot_perform_admin_operations`, `test_learner_view_hides_staff_only_fields` |

Additional protections: login rate limiting (A-AU `test_repeated_failed_logins_are_rate_limited`),
invalid/missing token (A-AU `test_requests_without_or_with_bad_token_are_rejected`), dedicated
transitions cannot be forced through the generic endpoint (A-RE `test_dedicated_transitions_cannot_be_forced…`).
